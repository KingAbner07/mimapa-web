# mi mapa. — sitio web

Quiz de venta de **mi mapa.** (México). Archivo único: `index.html`.

Antes de anunciar, edita el bloque `CONFIG` al inicio del script:
- `checkoutUrl` — link del checkout de Hotmart
- `metaPixelId` — ID del Pixel de Meta
- `gaMeasurementId` — ID de Google Analytics 4 (G-...)

Eventos enviados: PageView, QuizStarted, QuizStep (step_number, step_name), Lead, ViewContent, InitiateCheckout.
